# Module 1 Discovery Report: Antigravity IDE Quota & Telemetry Source Discovery

## 1. Executive Summary & Runtime Topology
Through filesystem inspection and live process telemetry on macOS Darwin (Apple Silicon arm64), the communication topology of Antigravity IDE (version 1.107.0) was mapped:
- **Core Agent / Language Server Process**: Executable `/Users/wandre/.gemini/bin/agy` (or legacy `language_server_macos_arm` / `language_server_windows_x64.exe`).
- **Command Line Arguments**:
  - `--hub`: Flag identifying daemon mode.
  - `--hub-port=<port>` (e.g. 51449): Primary Connect-Protocol HTTP server port.
  - `--extension_server_port=<port>`: Alternate / legacy port parameter.
  - `--csrf_token=<uuid>`: Security token for CSRF protection.
  - `--app_data_dir=antigravity`: Application directory identifier.
- **Network Interfaces**:
  - `127.0.0.1:<port>`: HTTP (Connect Protocol v1).
  - Port detection strategy: Parse running process arguments for `--hub-port` and `--extension_server_port`, or query `lsof -nP -a -iTCP -sTCP:LISTEN -p <pid>`.

## 2. API Endpoints & Protocol Handshake
- **Protocol**: HTTP/1.1 Connect Protocol (with HTTPS fallback support).
- **Required Headers**:
  - `Content-Type: application/json`
  - `Connect-Protocol-Version: 1`
  - `X-Codeium-Csrf-Token: <csrf_token>`
- **Method**: `POST`
- **Payload Body**:
  ```json
  {
    "metadata": {
      "ideName": "antigravity",
      "extensionName": "antigravity",
      "locale": "en"
    }
  }
  ```
- **Key RPC Services**:
  1. `/exa.language_server_pb.LanguageServerService/RetrieveUserQuotaSummary`:
     - Returns quota groups (`Gemini Models`, `Claude and GPT models`, `Gemini 4 Argon`).
     - Each group contains buckets with `remainingFraction` (float between 0.0 and 1.0), `window` (`"weekly"` or `"5h"`), and `resetTime` (ISO 8601 string).
  2. `/exa.language_server_pb.LanguageServerService/GetUserStatus`:
     - Returns user tier (`Pro`), monthly prompt credits (`monthlyPromptCredits`), available prompt credits (`availablePromptCredits`), and detailed model configurations with individual quota info.

## 3. Telemetry & Context Token Discovery
- **Context Storage Architecture**:
  - Antigravity IDE associates workspaces via workspace hash in `~/Library/Application Support/Antigravity IDE/User/workspaceStorage/<workspace_hash>/state.vscdb`.
  - In `state.vscdb`, table `ItemTable` with key `google.google-antigravity` stores `{"lastConversationId": "<uuid>"}`.
  - The live conversation transcript is persisted at:
    `~/.gemini/antigravity/brain/<lastConversationId>/.system_generated/logs/transcript.jsonl`.
  - Each step JSON object contains exact token telemetry:
    - `input_tokens`: New / prompt tokens.
    - `cache_read_tokens`: Tokens read from prompt cache.
    - `output_tokens`: Tokens generated by model.
- **Normalization Mapping**:
  - `contextTokensCached = lastStep.cache_read_tokens || 0`
  - `contextTokensNew = (lastStep.input_tokens || 0) + (lastStep.output_tokens || 0)`
  - `contextTokensTotal = contextTokensCached + contextTokensNew`
  - `contextUsedPct = Math.min(100, Math.round((contextTokensTotal / 1048576) * 100))` (based on 1M token window standard).

## 4. Resilience & Edge Cases
- **SQLite Concurrency**: When querying `state.vscdb`, SQLite may throw `SQLITE_BUSY` if Antigravity IDE holds a write lock. Mitigated via:
  - Read-only URI mode (`file:...mode=ro`).
  - Safe parsing of JSON directly with fallback if database is locked or not found.
  - Non-blocking async child process / worker reading without freezing extension host.
- **Process Lifecycle**: Daemon port changes when Antigravity IDE restarts; the client must detect connection drops and trigger dynamic re-discovery.
